【加密资产领域翻译规则】

1. 歧义默认按加密含义翻译：
   - Token = 代币（不译“令牌”）
   - Gas = Gas / 链上手续费
   - Wallet = 钱包
   - Exchange = 交易所
   - Stablecoin = 稳定币
   - Staking = 质押
   - Layer 2 / L2 = Layer2
   - TVL = 锁仓量（保留 TVL）

2. 协议、币种和产品名保留英文原文：Bitcoin、Ethereum、Solana、USDT、USDC。已有通用中文时可以并列一次，其后保持一致。

3. 地址、交易哈希、代码、数字和百分比一字不改。
