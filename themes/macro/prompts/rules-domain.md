【宏观经济领域翻译规则】

1. 歧义默认按宏观和外汇含义翻译：
   - Fed / FOMC = 美联储 / 联邦公开市场委员会
   - Hike / Cut = 加息 / 降息
   - QE / QT = 量化宽松 / 缩表
   - Basis point / bp = 个基点
   - Yield = 收益率
   - CPI / PPI / PMI / GDP = 保留英文缩写，可在首次出现时加中文
   - FX = 外汇
   - Intervention = 干预（汇率或市场操作）

2. 机构名用通用中文：美联储、欧洲央行、英国央行、日本央行、中国人民银行、中国证监会、国家金融监督管理总局、港交所、美国证监会。

3. 数字、日期、基点、百分比和货币代码保持原文，不换算单位。
